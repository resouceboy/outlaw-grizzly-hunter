# Outlaw Grizzly Hunter

![Outlaw Grizzly Hunter — Cover](images/Outlaw-Grizzly-Hunter-Font-01.jpg)

**Outlaw Grizzly Hunter** is a free Western display typeface by [Resource Boy](https://resourceboy.com/), inspired by the bold, distinctive wood-type lettering of the American Old West.

Our starting point was [Page No. 120](https://fontsinuse.com/typefaces/90534/page-no-120), a historic type design patented in 1880. Instead of making an exact revival, we approached it as a free interpretation: reshaping letterforms for contemporary use while keeping their rugged Western character. We spent hours refining glyphs, proportions, spacing, and kerning to make the font feel considered in every detail.

Made for expressive typography, it works especially well in posters, packaging, branding, apparel, and bold headlines.
